Statistics

Find mean, median and mode for grouped data and interpret distributions.

⭐ Ace Notes🎯 PYQ Pattern

⭐ Ace Notes

  • Mean can be found by direct, assumed-mean or step-deviation methods.
  • Median uses the cumulative frequency and median-class formula.
  • Mode uses the modal class and neighbouring frequencies.
  • Always identify class width, frequency and cumulative frequency correctly.
Median = l + [(N/2 − cf)/f]h; Mode = l + [(f₁−f₀)/(2f₁−f₀−f₂)]h.

🎯 PYQ Pattern Practice

These are original Xceed10 board-style questions modeled on the kinds of skills assessed by CBSE — not copied past-paper questions.

1. What does the median represent?
Answer approach

The central position of ordered data, adjusted for grouped classes using the median class.

2. What is the modal class?
Answer approach

The class interval with the highest frequency.

3. Why is cumulative frequency needed for grouped median?
Answer approach

It locates the class containing the N/2th observation.
