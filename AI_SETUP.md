# Xceed10 Smart Coach

This version uses a client-side original study knowledge base. It does not require a Gemini/OpenAI API key or a backend.

The Smart Coach matches a student's question to supported Xceed10 topics and returns an original explanation, example, practice question and chapter link.

It is intentionally not a general-purpose generative AI and cannot answer every unseen question. For broader coverage, expand the `knowledge` array in `ai.js` with original content.
