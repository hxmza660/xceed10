Introduction to Trigonometry

Build the right-triangle trigonometric ratios and standard-angle values.

⭐ Ace Notes🎯 PYQ Pattern

⭐ Ace Notes

  • For an acute angle in a right triangle: sin=opposite/hypotenuse, cos=adjacent/hypotenuse, tan=opposite/adjacent.
  • Reciprocal ratios: cosec, sec, cot.
  • Learn standard values at 30°,45°,60° and derive related values using identities.
  • Choose a ratio from the sides you actually know.
sin²A+cos²A=1; 1+tan²A=sec²A; 1+cot²A=cosec²A.
